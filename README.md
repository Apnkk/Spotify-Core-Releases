# Spotify Eevee & spoti.pw Combined Edition

Unified project containing both **EeveeSpotify** (Premium features, lyrics providers) and **spoti.pw** (Liquid Glass iOS UI redesign).

## Features
- **EeveeSpotify**: Free listening patch, custom lyrics integration (SpicyLyrics, Musixmatch, Genius, LRCLIB).
- **spoti.pw**: UIGlassEffect iOS redesign, Live Activity, custom gestures, audio effects.
- **Custom Credits**: Modified by Ares.

## Structure
- `EeveeSpotifyReincarnated-Master/`: EeveeSpotify tweak source code with custom credits.
- `spoti.pw-main/`: spoti.pw tweak source code with custom credits.
