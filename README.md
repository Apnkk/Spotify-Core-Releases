# Spotify Core By Ares — Releases

Public releases repository for **Spotify Core By Ares** (Combined Edition with EeveeSpotify Premium & Liquid Glass UI).

## 📥 Download

Check out the [Releases](https://github.com/Apnkk/Spotify-Core-Releases/releases) page to download the latest `.ipa` file.

## ✨ Features

- **EeveeSpotify Premium Integration**: Ad-free playback, unlimited skips, extreme audio quality, synchronized lyrics, and more.
- **Liquid Glass UI & Frosted Blur**: Translucent glassy interface with toggleable liquid effect.
- **Custom Accent Themes**: Ares Electric Purple, Cyberpunk Cyan, Sunset Crimson, Electric Gold, and custom color picker.
- **Custom App Icons**: 17 exclusive Ares app icon variants with live in-app switcher.
- **Real-Time Creator Profile**: Live Discord creator profile integration in settings.
- **In-App Updater**: Direct update notifications when a new IPA version is released.

## 📱 Installation

Install the `.ipa` using:
- **TrollStore** (iOS 14.0 – 17.0)
- **Feather / Scarlet / AltStore / Sideloadly**
